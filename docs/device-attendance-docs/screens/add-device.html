What happens on save

  1. 1
    Maugood connects to the device at host:port.
  2. 2
    Reads the serial number, model & firmware from /deviceInfo.
  3. 3
    Fernet-encrypts the username & password.
  4. 4
    Inserts one row into attendance_devices.
🔐
Credentials are encrypted at rest and never shown again after saving. They never appear in logs, audit rows, or API responses.
