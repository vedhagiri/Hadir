What this covers

Maugood computes attendance from a stream of “person seen at time T” events. Today those events come from IP cameras, where the server detects and matches every face. This project adds a second source — face-recognition terminals that match on-device and report the result — controlled by a per-tenant Attendance Source switch so only one pipeline runs at a time.

The attendance engine only reads (employee_id, captured_at) — it never knows whether a camera or a terminal produced the event. That is why the existing workflow continues unchanged when devices are added.
