🚪 Device-Based Attendance

How a face-recognition terminal produces attendance

A step-by-step walkthrough with dummy data — from adding the device to a finished attendance record.

➕

Step 1 · Add the device

Admin registers the terminal — host, login, and driver. The serial is read from the device itself.

Unique per tenant — the device's own fingerprint.

How the device connects to this engine
🚪 Mode A — Trust the device default

The terminal already matched on-board. Maugood just maps device_user → employee (from Step 4). Your engine is skipped — lightest CPU.

🧠 Mode B — Re-match in Maugood

The device sends the captured face. Maugood runs this exact engine — identical to a camera. Use it when Maugood must be the single source of identity truth.

🔁
Either way, the result is the same row in detection_events → and the same attendance. Your workflow downstream never changes.
✅
